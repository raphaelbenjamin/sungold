# Prototype interface sources

The prototype uses Radix UI primitives (MIT) and Lucide icons (ISC).
The reusable Sheet and Switch composition in `ui.tsx` is adapted from shadcn/ui,
with local CSS in place of Tailwind utilities:
https://github.com/shadcn-ui/ui/tree/main/apps/v4/registry/new-york-v4/ui

Settings layout reference: https://github.com/satnaing/shadcn-admin
(MIT, Copyright (c) 2024 Sat Naing). No application business logic is copied from it.
Linear and Readwise are visual references only. No paid templates are included.
Existing application code retains its GPL licence and attribution.
